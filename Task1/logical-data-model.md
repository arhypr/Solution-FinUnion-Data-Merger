# Логическая модель данных

## Назначение

Модель показывает ключевые сущности и связи, необходимые для единого клиентского профиля,
объединённой отчётности и синхронизации данных между FinUnion и RetailBank.

## ERD

Файл диаграммы: `diagrams/erd.puml` (PlantUML).

Краткая текстовая нотация связей (для быстрого просмотра без рендера):

```text
Клиент  1 ── N  Договор
Клиент  1 ── N  Счёт
Клиент  1 ── N  Обращение клиента
Клиент  N ── 1  Справочник (сегмент / отделение)

Договор N ── 1  Продукт
Договор 1 ── N  Счёт
Договор 1 ── 0..1 Кредит

Продукт 1 ── N  Тариф
Продукт N ── 1  Справочник (категория / код)

Счёт    1 ── N  Карта
Счёт    1 ── N  Транзакция
Счёт    1 ── N  Платёж

Карта   1 ── N  Транзакция
Кредит  1 ── N  Платёж
Платёж  1 ── N  Транзакция

Обращение клиента N ── 0..1 Договор
Обращение клиента N ── 0..1 Счёт
Обращение клиента N ── 0..1 Карта
Обращение клиента N ── 0..1 Кредит
