# Мастер-системы

## Роли систем

| Роль                             | Определение                                                                 | Примеры в ландшафте                                                      |
|----------------------------------|-----------------------------------------------------------------------------|--------------------------------------------------------------------------|
| Source System                    | Система, где данные физически хранятся сейчас                               | FU CRM, RB CRM, FU Core, RB Core, FU Cards, RB Cards, FU Loans, RB Loans |
| System of Entry                  | Система, где данные впервые появляются (создаются сотрудником или клиентом) | CRM (клиент), Core (счёт/договор/платёж), Cards (карта), Loans (кредит)  |
| Master System (System of Record) | Система, чьи данные считаются эталонными и распространяются в другие        | MDM, Core, Cards, Loans, CRM                                             |
| MDM / Customer Hub               | Компонент ведения золотой записи клиента                                    | MDM Customer Hub                                                         |
| Reference Data Management        | Компонент ведения справочников, продуктов, тарифов                          | RDM                                                                      |
| Integration Layer                | Маршрутизация и трансформация потоков                                       | ESB + Kafka + CDC                                                        |
| DWH                              | Аналитическое хранилище для отчётности и BI                                 | DWH                                                                      |
| DataHub / Data Catalog           | Метаданные, lineage, владельцы                                              | DataHub                                                                  |
| Data Lakehouse                   | История и события (целевое состояние, 12 мес)                               | Lakehouse                                                                |

**Важно:** MDM не назначается мастером для счетов, карт, кредитов, транзакций, платежей и договоров. Это операционные
данные, их эталон — профильная банковская система.

## Матрица мастер-систем

| Сущность          | Источники As-Is                                 | Мастер на +3 месяца                                                                               | Целевая мастер-система (12 мес)                    | Связь с BIAN                           | Обоснование                                                                                                                                              |
|-------------------|-------------------------------------------------|---------------------------------------------------------------------------------------------------|----------------------------------------------------|----------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Клиент            | FU CRM, RB CRM, FU Core, RB Core                | **MDM Customer Hub** (золотая запись), CRM — системы ввода                                        | **MDM Customer Hub**                               | Party Data Management                  | Разные `client_id` в FU и RB; без единого `party_id` невозможен единый профиль. MDM дедуплицирует и раздаёт golden record, CRM остаются системами ввода. |
| Счёт              | FU Core, RB Core                                | **FU Core** — для FU-счетов, **RB Core** — для RB-счетов (split); DWH — единое представление      | **FU Core** (единый Core)                          | Current Account / Savings Account      | Нельзя заменить RB Core за 3 месяца. Каждый Core — эталон по своим счетам, DWH консолидирует.                                                            |
| Договор           | FU Core, RB Core, FU Loans, RB Loans            | **Split по типу:** банковские — в соответствующем Core, кредитные — в соответствующей Loan System | **FU Core** (банковские), **FU Loans** (кредитные) | Customer Agreement                     | Договор юридически привязан к продукту и системе, где обслуживается. MDM здесь не подходит.                                                              |
| Продукт           | FU Core/CRM, RB Core/CRM, локальные справочники | **RDM** (единый каталог продуктов)                                                                | **RDM / MDM Reference**                            | Product Directory                      | Разные коды и названия продуктов; нужен единый каталог для отчётности и cross-sell.                                                                      |
| Тариф             | FU Core/Cards/Loans, RB Core/Cards/Loans        | **RDM** (управление версиями тарифов)                                                             | **RDM / MDM Reference**                            | Product Pricing / Fee                  | Тарифы различаются между организациями; централизованное версионирование исключает расхождения в начислениях.                                            |
| Карта             | FU Cards, RB Cards                              | **FU Cards** — FU-карты, **RB Cards** — RB-карты (split); DWH — единое представление              | **FU Cards** (единый процессинг)                   | Card Management                        | Процессинг — специализированная система. MDM не подходит: карта — платёжный инструмент, а не справочник.                                                 |
| Кредит            | FU Loans, RB Loans                              | **FU Loans** — FU-кредиты, **RB Loans** — RB-кредиты (split); DWH — единое представление          | **FU Loans** (единая кредитная система)            | Consumer Loan / Corporate Loan         | Кредитная система — эталон по параметрам, скорингу и просрочке. MDM не подходит.                                                                         |
| Транзакция        | FU Core, FU Cards, RB Core, RB Cards            | **Источник, проводивший операцию** (Core — по счёту, Cards — по карте)                            | **FU Core** (счётные), **FU Cards** (карточные)    | Financial Transaction Capture / Ledger | Транзакция — событие. Эталон — система, которая её провела. В DWH и Lakehouse — консолидированное представление.                                         |
| Платёж            | FU Core, RB Core, FU Loans, RB Loans            | **Источник, проводивший платёж** (Core — банковские, Loans — кредитные)                           | **FU Core** (банковские), **FU Loans** (кредитные) | Payment Execution / Payment Order      | Платёж — поручение, его эталон — система, исполняющая платёж. MDM не подходит.                                                                           |
| Обращение клиента | FU CRM, RB CRM, контакт-центр                   | **FU CRM** — принимает все обращения (включая RB-клиентов); RB CRM — feeder                       | **FU CRM**                                         | Customer Case Management               | Одна CRM в целевой модели. В переходный период FU CRM — точка консолидации, RB CRM остаётся источником по RB-клиентам.                                   |
| Справочник        | Локальные справочники всех систем               | **RDM**                                                                                           | **RDM / MDM Reference**                            | Reference Data Management              | Без единых справочников (отделения, сегменты, коды операций) невозможны сопоставление и отчётность.                                                      |

## Как BIAN помогает определить границы владения

| BIAN-домен                             | Кто владеет     | Что это даёт                                                                             |
|----------------------------------------|-----------------|------------------------------------------------------------------------------------------|
| Party Data Management                  | MDM             | Единый `party_id` и golden record клиента; CRM/Core — только потребители и системы ввода |
| Current Account / Savings Account      | Core Banking    | Core — эталон по счёту и остаткам; аналитика — через DWH                                 |
| Customer Agreement                     | Core / Loans    | Договор не «размазывается» по MDM и CRM                                                  |
| Product Directory                      | RDM             | Единый каталог продуктов вместо локальных справочников                                   |
| Product Pricing / Fee                  | RDM             | Управление тарифами и версиями в одном месте                                             |
| Card Management                        | Card Processing | Процессинг — эталон по карте, статусам и токенам                                         |
| Consumer Loan / Corporate Loan         | Loan System     | Loan System — эталон по кредитному портфелю                                              |
| Financial Transaction Capture / Ledger | Core / Cards    | Эталон — система, проводившая операцию; DWH/Lakehouse — консолидация                     |
| Payment Execution / Payment Order      | Core / Loans    | Эталон — система исполнения платежа                                                      |
| Customer Case Management               | CRM             | Одна CRM — единая точка обращений                                                        |
| Reference Data Management              | RDM             | Единые справочники с владельцами и версиями                                              |
