# Управление потоками данных

## Соглашения

- **SLA** — допустимое время доставки данных от источника до приёмника (от события до готовности к использованию).
- **Тип обмена** — Sync / Async / Batch / Streaming / CDC.
- **Контроль качества** — обязательные проверки на потоке.
- **Мониторинг** — что отслеживается в проде.

## Правила управления потоками

1. **Каждый поток имеет владельца** — команда, отвечающая за SLA и качество.
2. **Все потоки идут через Integration Layer**, кроме sync-запросов к MDM/RDM. Point-to-point интеграции RB выводятся из
   эксплуатации по графику Task4.
3. **Схемы данных версионируются** (Schema Registry); breaking changes — только через согласование Data Office.
4. **DLQ обязателен** для всех асинхронных потоков; обработка DLQ — не реже 1 раза в сутки.
5. **Персональные данные в потоке** — маскирование или токенизация (обращения, реквизиты).
6. **Lineage** — каждый поток регистрируется в DataHub.
