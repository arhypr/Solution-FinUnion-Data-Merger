## Принципы

1. **Один владелец на сущность** — не бывает «совместного владения» для master-системы.
2. **Data Steward ≠ Data Owner:** Owner отвечает за бизнес-смысл, Steward — за качество и правила.
3. **Producer ≠ Master:** CRM создаёт клиента, но эталон — MDM. Core создаёт транзакцию, эталон — Core (это и producer,
   и master).
4. **Удаление по 152-ФЗ** — процесс через MDM: MDM блокирует клиента и рассылает событие `Delete/Block` в
   системы-потребители; физическое удаление — по retention-политике.
5. **Изменение master-данных** — только через систему-владельца; другие системы не пишут в master, а получают
   обновления.
